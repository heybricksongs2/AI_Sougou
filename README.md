# ⚡ Neon Breakout (ネオンブロック崩し)

ブラウザで遊べるスタイリッシュなネオン調のブロック崩しゲームです。GitHub Pages上で直接プレイできます。

## 🎮 プレイURL
👉 **https://heybricksongs2.github.io/AI_Sougou/**

## ✨ 特徴
- **PC & スマホ両対応**: マウス操作、キーボード（`←` `→` / `A` `D`）、画面タッチ/スワイプに対応
- **シンセ効果音**: Web Audio API による軽快なレトロサウンド（音量ON/OFF切り替え可能）
- **パーティクル演出**: ブロック破壊時やパドル反射時にネオン粒子が散るビジュアルエフェクト
- **コンボシステム & ハイスコア**: 連続破壊でボーナス得点、スコアはブラウザに自動保存
