# 🔐 POP LOCK RUSH! (ポップ・ロック・ラッシュ)

言語不要！画面のピクトグラムや直感操作でテンポよく解錠していくスピードアクションゲームです。

## 🎮 プレイURL (GitHub Pages)
👉 **https://heybricksongs2.github.io/AI_Sougou/**

## 🕹️ 基本ルール
- **初期制限時間**: 18.0秒
- **時間延長**: 鍵を1つ解錠するごとに **+0.5秒** 追加！
- **出題システム**:
  - **1周目 (Round 1)**: 超簡単な Lv.1 から最高難度の Lv.30 まで難易度順に順番に出現！
  - **2周目 (Round 2〜)**: 全30種類の中から**完全ランダム**に出現！
