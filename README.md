# 🔐 POP LOCK RUSH! (ポップ・ロック・ラッシュ)

指示テキストゼロ！完全ノンバーバル（非言語）で、直感的なマークやギミックを瞬時に解いていく超爽快スピード解錠アクション！

## 🎮 プレイURL (GitHub Pages)
👉 **https://heybricksongs2.github.io/AI_Sougou/**

## 🕹️ 基本ルール
- **初期制限時間**: 18.0秒
- **時間延長**: 鍵を1つ解錠するごとに **+1.0秒** 追加！
- **カードスタック演出**: 立体カード構造により、解錠時に次のカードがスムーズにアクティブ化。
- **出題システム**:
  - **1周目 (Round 1)**: Lv.1 〜 Lv.24 まで難易度順に順番に出現！
  - **2周目 (Round 2〜)**: 全24種類の中から**完全ランダム**に出現！

## 🛠️ デバッグモード機能
画面右上の **`🛠️` ボタン**、スタート画面の **`DEBUG MODE` リンク**、キーボードの **`D` キー**、またはURL末尾に **`?debug=1`** を付与すると「DEBUG PANEL」が開きます。
- **JUMP 🚀**: ドロップダウンから任意のレベル（Lv.1〜24）を選んで即座にテストプレイ可能
- **PASS 🔓**: 現在のギミックを強制解錠して次へ進む
- **FREEZE ⏱️**: 制限時間タイマーを一時停止 / 再開（時間を気にせず検証可能）
- **+10s ⏳**: 残り時間を+10秒追加
- **END 💀**: リザルト画面をテスト表示
