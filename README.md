# 🔐 POP LOCK RUSH! (ポップ・ロック・ラッシュ)

画面の指示を見て瞬時に解錠していく、スピード解錠サバイバルゲームです。

## 🎮 プレイURL (GitHub Pages)
👉 **https://heybricksongs2.github.io/AI_Sougou/**

## 🕹️ 基本ルール
- **初期制限時間**: 18.0秒
- **時間延長**: 鍵を1つ解錠するごとに **+0.5秒** 追加！
- **完全巡回システム**:
  - 最初は一番簡単な Lv.1 からスタートし、解錠するごとにどんどん難しい鍵へ進行（Lv.1 → Lv.10）。
  - **一度解いた鍵は、他の全9種類を解き終えるまで絶対に再出現しません！**
  - 10種類すべてを突破すると「ROUND 2」へ突入し、さらなるボーナススコアと難関周回へ挑戦できます。

## 🔑 10種類の難易度別ギミック一覧
1. **Lv.1 ワンタップ** (★☆☆☆☆): ボタンをポチッと1回押す
2. **Lv.2 電源スイッチ** (★☆☆☆☆): スイッチをタップしてONに切り替える
3. **Lv.3 鍵差し込み** (★★☆☆☆): 「🔑鍵」をタップして鍵穴に挿入
4. **Lv.4 ダブルタップ** (★★☆☆☆): リズムよく素早く2回タップ
5. **Lv.5 横スライド** (★★★☆☆): つまみを右端のGOALまでスワイプ
6. **Lv.6 上引きレバー** (★★★☆☆): かんぬきを真上へ引き上げる
7. **Lv.7 カラー二択判断** (★★★★☆): 指定された色（青/赤）を瞬時に選ぶ
8. **Lv.8 激連打ロック** (★★★★☆): ゲージが満タンになるまでボタンを猛連打
9. **Lv.9 長押しチャージ** (★★★★★): ボタンをホールドしてサークル満タンで離す
10. **Lv.10 ダイヤル合わせ** (★★★★★): ダイヤルをタップして▲マークを真上に揃える
