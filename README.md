# 🔐 POP LOCK RUSH! (ポップ・ロック・ラッシュ)

言語不要！画面のピクトグラムや直感操作でテンポよく解錠していくスピードアクションゲームです。

## 🎮 プレイURL (GitHub Pages)
👉 **https://heybricksongs2.github.io/AI_Sougou/**

## 🕹️ 基本ルール
- **初期制限時間**: 18.0秒
- **時間延長**: 鍵を1つ解錠するごとに **+0.5秒** 追加！
- **完全巡回デッキ**:
  - 最初は超簡単な Lv.1 からスタートし、進むごとにどんどん手応えのある鍵へステップアップ（Lv.1 → Lv.15）。
  - **一度解いた鍵は、他の全14種類をすべて解き終えるまで再出現しません！**
  - 全15種類を解破すると次周（Round 2）へ突入し、さらなるハイスコアを目指せます。
