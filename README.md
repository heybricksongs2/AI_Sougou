# GitHub Pages Static Site

シンプルな HTML / CSS / JavaScript で構築された GitHub Pages 用のウェブサイトです。

## 構成ファイル

- `index.html`: メインページ
- `style.css`: スタイルシート
- `main.js`: スクリプト（クリックカウンター）
- `.gitignore`: Git 除外設定

## デプロイ手順

1. GitHub で新規リポジトリを作成します。
2. ローカルのファイルをコミットしてプッシュします。
3. リポジトリの **Settings** > **Pages** でデプロイ元ブランチに `main` を指定します。
4. 数分後に公開 URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）でアクセス可能になります。
