# 🔐 POP LOCK RUSH! (ポップ・ロック・ラッシュ)

画面の指示を見て瞬時に解錠していく、スピード解錠サバイバルゲームです。

## 🎮 プレイURL (GitHub Pages)
👉 **https://heybricksongs2.github.io/AI_Sougou/**

## 🕹️ 基本ルール
- **初期制限時間**: 18.0秒
- **時間延長**: 鍵を1つ解錠するごとに **+0.5秒** 追加！
- **難易度**: 解錠するごとに難易度★（得点）がアップ

## 🔑 10種類のシンプル解錠ギミック
1. **ワンタップ**: ボタンをポチッと1回押す
2. **激連打**: ゲージが満タンになるまでボタンを猛連打
3. **横スライド**: つまみを右端のGOALまでスワイプ
4. **上引きレバー**: かんぬきを真上へ引き上げる
5. **電源スイッチ**: スイッチをタップしてOFFからONに切り替える
6. **ダブルタップ**: トントンと素早く2回タップ
7. **カラー二択**: 指定された色のボタン（青/赤）を瞬時に選んでタップ
8. **長押しチャージ**: ボタンを長押ししてサークルが満タンになったら離す
9. **鍵差し込み**: 「🔑鍵」をタップして鍵穴に差し込む
10. **ダイヤル合わせ**: ダイヤルをタップして▲マークを真上に合わせる
