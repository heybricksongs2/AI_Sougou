# 🔐 POP LOCK RUSH! (ポップ・ロック・ラッシュ)

次々と現れる多種多様な鍵をすばやく解錠していく、スピード解錠サバイバルゲームです。

## 🎮 プレイURL (GitHub Pages)
👉 **https://heybricksongs2.github.io/AI_Sougou/**

## 🕹️ ルール
- **初期制限時間**: 18.0秒
- **時間延長**: 鍵を1つ解錠するごとに **+0.5秒** 追加！
- **ギミックバリエーション**:
  1. **クイックタップ**: 1回素早くボタンを押す
  2. **高速連打ロック**: ゲージが満タンになるまでボタンを激しく連打
  3. **ボルトスライド**: スライダーをつまんで右端のゴールまで引き切る
  4. **タイミング合わせ**: 回転する針がグリーンのゾーンに入った瞬間にストップ
  5. **コードピン暗号**: 光る番号を `1 → 2 → 3...` と順番に押す
- **難易度とスコア**: 解錠していくにつれて難易度が上昇し、高難度の鍵ほど大量得点
- **立体カードスタック**: 手前に今解く鍵、背後に次に解く鍵が半透明で表示
